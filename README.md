### 🔭 Out in the open

**[clippush](https://github.com/yohangwak/clippush)** · `Shell` · MIT

> Copy any file on your Mac → paste it into a remote AI coding agent
> (Claude Code, Codex, opencode, aider) over SSH.
> Any file, multiple at once.

Your remote terminal can't see your local clipboard, so pasting a screenshot
into an agent over SSH just fails. `clippush` is the `scp` you'd have typed,
with every step around it removed: copy, run `clippush`, paste.
